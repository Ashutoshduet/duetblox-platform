Source downloads

DUETBlox is an independent application built with official Scratch components. Its application source, modifications, build scripts and license notices are available here.

Download DUETBlox source ZIP

The ZIP contains the application source and pinned npm lockfiles. The full upstream source trees below complement it, including their original licenses, source assets, build scripts and tests. Scratch component code uses AGPL-3.0-only; individual dependency licenses are retained in their archives.

Build the current browser release

From the application source ZIP, install the pinned dependencies, fetch the checksum-pinned model/media pack, then build:

npm ci
npm --prefix apps/scratch-editor ci
npm run offline:download
node scripts/restore-source-packets.mjs
npm run build

The full laptop handoff already includes model and media files. Normal builds verify them. See the source ZIP’s README and docs/offline-models.md for exact configurations and notices.

Verify source downloads

The download links above return complete archives. Compare each file with its SHA-256 shown in the table, for example:

shasum -a 256 scratch-editor-15.2.0-970132883d63.tar.gz

To restore all source packets into an extracted DUETBlox source ZIP or fresh Git checkout, run node scripts/restore-source-packets.mjs. It downloads from these pinned URLs, verifies complete archives and split parts, and restores the hardware packets. It does not execute downloaded source code.

For the split files already in the laptop handoff, python3 reassemble.py verifies and joins the four editor parts. SHA256SUMS refers to those local packet names. Direct official downloads do not need joining. Source downloads require internet; app offline preparation is separate.

The Translate extension language-data repository was unavailable at packaging time. Its exact published npm source package is provided, including the generator, tests, data and BSD license. Other third-party dependencies and build tools are pinned by the upstream and DUETBlox lockfiles and are fetched by npm. A full offline dependency mirror is not included. See BUILDING.txt for the scope of verification and source-build instructions.
