DUETBlox changes are in src/, webpack.config.cjs and scripts/. Reproducible build:
  npm ci
  npm run build
The build emits ../../public/scratch. npm dependencies and integrity hashes are
pinned by package-lock.json. The npm packages include upstream source files.

The build modifies copied upstream bundles in these explicitly audited ways:
- Webpack lazy-asset paths use /scratch/ and /scratch/vendor/ instead of /.
- Localhost uses upstream's inline sandbox script delivery path to work with
  current browser private-network protections, without weakening iframe sandbox.
- The default English project title uses DUETBlox branding.
- The unused hull.js dynamic point-format converters are replaced by converters
  accepting only ordinary coordinate arrays, removing the Function-based code
  injection primitive described in GHSA-q849-wxrc-vqrp. Scratch's inspected caller
  passes no format parameter; normal geometry behavior is preserved.

Source for these changes and build instructions is provided with DUETBlox's
source download. Component sources can also be obtained from the exact npm
package versions and the official repositories above. Applicable copyright,
license, third-party notices and trademark notices must be preserved.
