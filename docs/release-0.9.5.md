# DUETBlox 0.9.5 — A clearer first activity

Students can start a guided Junior story directly from the workspace or lesson page. The previous complete workspace is protected in My projects → Recovery copies before the story changes. If local storage cannot protect the old work, the starter does not open. Existing Scratch, model and circuit sections remain in the current workspace.

The home screen separates concrete first activities from returning to existing work. It includes a prominent no-board Circuit Lab entry, larger text, and controls sized for touch. Learn and My projects precede advanced tools in the sidebar.

The old unconditional saved label is replaced with observed browser-write feedback. Storage failures stay visible and provide a project-backup download action. A successful unrelated write cannot conceal a previous failure. This status describes storage transactions, not all unsaved changes in every editor.

See `student-comparison-2026-11.md` for the evidence-based competitor comparison and remaining student, hardware, debugging and classroom limitations. Test logs and screenshots are kept under `work/student-audit-20261126/` in the laptop checkout. No child usability study or real-board validation is claimed.
